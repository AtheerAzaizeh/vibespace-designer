# VibeSpace Designer

**الموقع:** https://tourmaline-salamander-b330d0.netlify.app/

أداة ويب لإعادة تصميم غرفة أو زاوية مكتب بالميزانية المتاحة. المستخدم يختار الطابع (دافئ، عصري بسيط، طابع كافيه، استوديو إبداعي) ويحدّد ميزانيته بالشيكل، فيحصل على معاينة «قبل وبعد»، لوحة ألوان، اقتراحات إضاءة وتوزيع، وقائمة تسوق بقطع حقيقية من **IKEA ישראל** و**Fox Home** و**Home Center** مع رابط مباشر لكل منتج.

## ما الذي في الصفحة

| الجزء | الوصف |
|---|---|
| قبل/بعد | غرفة نموذجية مرسومة بـ Canvas تتغير مع الطابع والقطع المختارة. رفع صورة حقيقية يعطي تلويناً تقريبياً فقط، والصورة لا تغادر المتصفح. |
| قائمة التسوق | ملاءمة تلقائية (قطعة واحدة لكل فئة حتى نفاد الميزانية)، تعديل يدوي، نسخ القائمة، مشاركة رابط، إرسال عبر واتساب. |
| لوحة الألوان | خمسة ألوان لكل طابع، تجربة اللون على الجدار، نسخ الأكواد. |
| نموذج الربح | عمولة تقديرية للسلة والباقات. النسب افتراضية ومذكور ذلك في الصفحة. |
| المصادر | تاريخ آخر تحقق من الأسعار وشروط كل متجر. |

## البنية

```
index.html              الصفحة الرئيسية (عربية، RTL)
privacy.html terms.html صفحات قانونية + إفصاح عن روابط الشراكة
assets/css/app.css      التصميم (نهاري/ليلي، متجاوب)
assets/js/app.js        الحالة، الواجهة، رابط المشاركة
assets/js/room.js       رسم الغرفة وتلوين الصور
data/catalog.json       الكتالوج: الطوابع والمنتجات والأسعار (مصدر الحقيقة الوحيد)
data/catalog.schema.json مخطط JSON للكتالوج
scripts/check-prices.mjs يقرأ الأسعار الحية من المتاجر ويحدّث الكتالوج
tests/                  اختبارات node:test للكتالوج وخوارزمية الملاءمة
sw.js manifest.webmanifest  PWA: يعمل دون اتصال ويُثبَّت على الهاتف
.github/workflows/      اختبار + نشر على GitHub Pages، وفحص أسعار أسبوعي يفتح PR
```

لا توجد تبعيات بناء. الموقع ملفات ثابتة يمكن استضافتها على أي خادم.

## التشغيل محلياً

```bash
npm test          # اختبارات
npm run serve     # http://localhost:4173
npm run prices    # مقارنة الأسعار الحالية بالكتالوج دون تعديل
npm run prices:write  # تحديث catalog.json بالأسعار الحية
```

## تحديث الأسعار

`data/catalog.json` هو مصدر الحقيقة. الـ workflow `prices.yml` يعمل كل يوم اثنين، يقرأ كل صفحة منتج، وإن تغيّر سعر يفتح Pull Request بعنوان «Weekly price refresh». راجعه وادمجه لينشر الموقع تلقائياً. إن فشل قراءة أي منتج لا يُحدَّث الملف، ويظهر السبب في سجل الـ Action.

## إضافة منتج

أضف كائناً إلى `products` للطابع المناسب:

```json
{ "sku": "ikea-12345678", "cat": "rug", "name": "اسم الموديل ووصف قصير", "store": "ikea", "price": 295, "url": "https://www.ikea.com/il/he/p/.../12345678/" }
```

`cat` من قائمة `categories`، `store` من `stores`، `url` صفحة المنتج نفسها. شغّل `npm test` قبل الدفع.
